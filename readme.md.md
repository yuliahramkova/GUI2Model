# GUI2Model

## Проблема

Современные LLM-агенты, работающие с GUI (Computer Use Agent), тратят
значительные ресурсы на разведку интерфейса перед его использованием:
много токенов уходит на просмотр экрана, кликаемые элементы,
семантику разделов. На каждом новом запуске эта работа повторяется
почти с нуля.

## Предложение

Разработать методы **выучивания информации об GUI** моделью так,
чтобы при последующих запусках агент уже знал про интерфейс и не
тратил бюджет токенов на его повторное исследование.

Задача распадается на две подзадачи: **exploration** (как добыть знание
об GUI) и **distillation** (как переложить это знание в модель).

### Exploration — получение информации об GUI

- **Из интернета / документации приложения.** Поиск открытых
  материалов о приложении (документация, скриншоты, обучающие
  видео) и извлечение оттуда информации о структуре GUI.
  *Подзадача, удобная для практической работы.*
- **Через A11y (accessibility tree).** Уже есть наработанный метод —
  опираться на дерево доступности приложения как на «голый» источник
  структуры GUI.
- **Через CUA на крупной модели.** Уже есть метод — большой CUA
  обходит интерфейс и собирает разметку/трейсы действий, из которых
  строится описание GUI.

### Distillation — переложить знание об GUI в модель

- **Без обучения, через граф знаний (light-RAG).** Модель не
  обучается, но знания об UI поданы ей в связанном виде (граф),
  что облегчает понимание структуры интерфейса в момент работы.
- **doc2lora.** Конвертация описания GUI в LoRA-адаптер, который
  подгружается к модели.
- **SFT.** Дообучить модель полной информацией о GUI через
  supervised fine-tuning.

## Контекст: откуда задача

Задача является развитием внутренней R&D-темы лаборатории по
автоматизированному превращению старых GUI-приложений в MCP-тулсеты
(подход «GUI2MCP»):

## Ожидаемый результат практики

- Прототип одной из веток (exploration или distillation), доведённый
  до измеримого качества на выбранном бенчмарке.
- Сравнение полученного подхода с baseline (CUA без предзнания GUI).
- Краткий отчёт + код, который может быть подхвачен лабораторией для
  дальнейшего развития.
